# bln-markdown-preview

Free online Markdown editor with live preview, syntax highlighting, and writing quality checks.

## Features

- Free to use, no login required
- Privacy-first: all processing happens in-browser
- Mobile-friendly responsive design
- Part of the [BeLikeNative](https://belikenative.com) open-source toolkit
